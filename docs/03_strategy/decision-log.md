## 2026-02-15 — Establish Linear Hub as SSOT

- **Context**: Linear TV team needed a centralized system for data analysis, competitive intelligence, and strategy documentation. Information was scattered across dashboards, docs, and ad-hoc analyses.
- **Options considered**:
  1. Continue using existing dashboards + Google Docs
  2. Build a centralized repo with Claude Code skill integration
  3. Use a third-party competitive intel platform
- **Decision**: Build the Linear Hub repo with 3 Claude skills (data, research, strategy) and automated competitive intelligence pipeline.
- **Rationale**: Claude Code skills provide natural language interface to Databricks data + competitive intel + strategy docs in one place. The automated scanner pipeline provides repeatable, scalable competitive monitoring.
- **Expected outcome**: Single source of truth for all linear TV work. Faster analysis cycles. Automated competitive monitoring.
- **Owner**: Rahul Rao (DSA)
- **Review date**: 2026-03-15
