# H1 FY26 Linear TV Strategy — Approved Plan Summary

> Owner: Brian Fusco | Last updated: Jun 13, 2025 | Status: Published

## Vision

All Tubi viewers find value in Linear TV. Linear complements VOD by offering scheduled programming, live content, and a casual lean-back experience.

## Strategy Pillars

1. **Top-of-funnel growth** — Off-platform placements, temporal marketing, live events
2. **Personalization** — Program-level signals to enhance recommendations
3. **Ad Load** — Redistribute from VOD to linear (grow revenue + improve UX)
4. **Content Verticals** — Augment VOD catalog with aligned linear channels
5. **Discovery Experience** — Seamless channel browsing, program-forward discovery

## FY26 Goals (US-only, excludes Sea Tiger)

- Raise Linear TVT share: 6.5% → 9.0%
- Required YoY linear TVT growth: +59.25%
- Incremental TVT: ~25.6M hrs/month
- Net lift (50% cannibalization): ~12.8M hrs → 1.26% global TVT
- H1 target: +0.50% incremental TVT lift
- H2 target: +2.02% incremental TVT lift

## H1 Themes

1. **Elevate Tubi as live events destination** (Super Bowl success → NFL → World Cup)
2. **Discover linear programs most relevant to you** (program-level ranking, personalization)
3. **Reach a larger audience** (detail pages, off-platform, UK launch)
4. **Faster channel browsing** (unified EPG, updated player UX)
